# Security Policy

This repository holds the source of kyberlib.com. Report a vulnerability
in the website, or in the kyberlib library it describes, privately to
**contact@kyberlib.com**, the address in the library's
[security policy](https://github.com/sebastienrousseau/kyberlib/security/policy).
Machine-readable disclosure metadata lives at
[`/.well-known/security.txt`](.well-known/security.txt) per
[RFC 9116](https://www.rfc-editor.org/rfc/rfc9116).

Please do **not** open a public GitHub issue for a suspected security
vulnerability: email first to coordinate disclosure.
