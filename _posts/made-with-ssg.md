## How is this site built?

kyberlib.com is generated by
[Static Site Generator](https://static-site-generator.com/) (SSG), an
open-source generator written in Rust, using the Prism theme with a palette
taken from the kyberlib logo. Each change to the site's repository is built
by GitHub Actions and deployed to GitHub Pages; nothing built is committed.

## What does the build check?

Every build checks the colour contrast of the theme, then runs the
generator's quality gate and audit: structured data, links, metadata,
accessibility, the content security policy and Subresource Integrity hashes.
A failure stops the deployment.
